Privacy policy

Hermes Agent is a personal assistant used by a single person, its owner. It is not available to the public.

Data accessed

With the owner's consent, the agent reads the owner's own mailbox (Gmail API scopes gmail.readonly and gmail.compose) to summarise messages and prepare reply drafts. A message is sent only after the owner explicitly approves it.

Use and sharing

Data is used solely to assist the owner. It is not sold, shared with third parties, used for advertising, or used to train models. Language-model requests go to zero-data-retention endpoints.

Storage and deletion

Access tokens are stored on infrastructure controlled by the owner and can be revoked at any time from myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
